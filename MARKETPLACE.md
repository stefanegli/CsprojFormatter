# CsProjFormatter

Formats SDK-style `.csproj` files after saving: sorts supported entries, normalizes XML formatting, and applies consistent spacing.

Use only with a source control system and at your own risk. See the [change log](https://github.com/stefanegli/CsProjFormatter/blob/master/CHANGELOG.md) for changes and road map.

# Getting started

Formatting rules are configured through EditorConfig. Refer to the [settings documentation](https://github.com/stefanegli/CsProjFormatter#settings) for the available options and examples.
